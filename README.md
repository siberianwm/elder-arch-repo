# elder-arch-repo

Личный pacman-репозиторий. Пакеты собираются **из исходников** официальных
проектов на раннерах GitHub, подписываются GPG и публикуются на GitHub Pages.
Обновление на машине идёт штатно — через `pacman -Syu` / CachyUpdate.

## Что внутри

| пакет | источник | версия |
|---|---|---|
| `xray-core` | [XTLS/Xray-core](https://github.com/XTLS/Xray-core) | последний тег (включая pre-release) |

### Почему не AUR

XTLS помечает **все** свежие сборки как pre-release. Пакеты `xray` и `xray-bin`
в AUR ориентируются на последний «стабильный» релиз и потому отстают на месяцы
(на момент создания репозитория — 26.3.27 против актуальной 26.7.11).
Пакет `3x-ui-xray-core` версию держит свежую, но кладёт бинарь в
`/usr/lib/x-ui/bin/` и в `post_install` тянет geo-базы с трёх сторонних
репозиториев — лишнее расширение круга доверия.

## Как работает

```
раз в сутки Actions просыпается по расписанию
   ↓
GitHub API: какой сейчас последний тег у XTLS?
   ↓
новее нашего? → правит в PKGBUILD версию и пересчитывает хеши
   ↓
docker run archlinux:base-devel
   ↓
makepkg --sign: качает исходники по тегу, сверяет хеш, собирает, подписывает
   ↓
repo-add --include-sigs → база репозитория
   ↓
публикация на GitHub Pages
```

Сборка идёт из архива `/archive/v<тег>/`, который GitHub **генерирует из git-тега
автоматически** — в отличие от release-ассетов, его нельзя подменить, не переписав
историю репозитория. Это защита от сценария вроде бэкдора в xz (CVE-2024-3094),
где вредонос лежал в релизном тарболе, но отсутствовал в git.

## Подключение на машине

### 1. Импортировать ключ подписи

```bash
curl -fsSL https://siberianwm.github.io/elder-arch-repo/elder-arch-repo.pub -o /tmp/repo.pub
sudo pacman-key --add /tmp/repo.pub
sudo pacman-key --finger 449CC3B82FDE9ACB     # сверить отпечаток
sudo pacman-key --lsign-key 449CC3B82FDE9ACB  # локально подписать = доверять
```

Отпечаток ключа:

```
44C0 BF69 2AF2 A834 B673  98B7 449C C3B8 2FDE 9ACB
```

### 2. Добавить репозиторий

В конец `/etc/pacman.conf`:

```ini
[elder-arch-repo]
SigLevel = PackageRequired
Server = https://siberianwm.github.io/elder-arch-repo/$arch/
```

`PackageRequired` — подпись пакетов обязательна. Не использовать `TrustAll`:
он существует для отладки и означает доверие любому непроверенному ключу.

### 3. Установить

```bash
sudo pacman -Syu
sudo pacman -S xray-core
```

Пакет конфликтует с `xray` и `xray-bin` из AUR — если они стоят, pacman предложит
замену. Установленный вручную бинарь в `/usr/local/bin/xray` pacman не видит,
его нужно удалить самому, иначе он перекроет пакетный по `$PATH`.

## Добавление нового пакета

1. Создать `packages/<имя>/PKGBUILD`
2. Закоммитить — workflow соберёт всё, что лежит в `packages/*/`

Автоматическое отслеживание версии сейчас настроено только для `xray-core`
(шаг «Узнать актуальную версию»); для остальных пакетов версия правится вручную.

## Секреты репозитория

| имя | назначение |
|---|---|
| `GPG_PRIVATE_KEY` | приватный ключ подписи (armor) |
| `GPG_PASSPHRASE` | пароль от него |
| `GPG_KEYID` | ID ключа: `449CC3B82FDE9ACB` |

Ключ выпущен **только** для подписи пакетов этого репозитория и не используется
больше нигде. При компрометации — отозвать сертификатом отзыва и перевыпустить.
